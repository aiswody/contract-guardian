# 라벨링 가이드라인 (Labeling Guideline)

> 시드 문장의 위험도·카테고리 라벨 판단 기준과 경계 사례 모음.
> 스펙 §5.2 Step 2의 산출물. `docs/risk-pattern-matrix.md`(유형표)와 짝을 이룬다 —
> 유형표는 "어떤 패턴이 어느 칸인가", 이 문서는 "경계에 걸린 문장을 어떻게 판정하는가".
> 작성일: 2026-07-12 / 상태: v0.2 (1차 파일럿 결과 반영 — §7 갱신 이력 참조)

## 1. 라벨 대상

| 축 | 값 | 비고 |
|---|---|---|
| 위험도 (3-class) | `safe` / `caution` / `danger` | `uncertain`은 모델 출력 상태이지 라벨이 아님 |
| 카테고리 (7-class) | `deposit_return` / `repair_defect` / `restoration` / `termination_renewal` / `lien_rights` / `fees_utilities` / `etc` | 코드 정의는 유형표 참조 |

라벨링 단위는 **조항 1문장(또는 1항)**이다. 여러 문장이 하나의 특약 번호로 묶여 있어도,
독립적으로 위험을 판단할 수 있으면 문장 단위로 분리해 각각 라벨링한다.

## 2. 위험도 판정 원칙

**관점 고정: 임차인(세입자) 입장에서 판단한다.** 임대인에게 불리한 조항은 임차인 기준으로 safe다.

**판정은 "문면(문구 그대로)" 기준이다.** 실제 법적 효력(강행규정 위반으로 무효인지 등)은
고려하지 않는다. 갱신요구권 포기 특약은 법적으로 무효지만, 임차인이 그 사실을 모르면
권리 행사를 포기하게 되므로 문면 그대로 danger로 라벨링한다.
(이 서비스의 목적은 법률 판단이 아니라 "서명 전에 알아채게 하는 것"이다.)

### 2.1 판정 절차 (위에서부터 순서대로 적용, 먼저 걸리는 것으로 확정)

1. **법정 권리의 포기·제한을 문면에 포함하는가?**
   (갱신요구권 포기, 전입신고·확정일자 제한, 임차권등기 금지, 이의 제기 포기 등)
   → **danger**
2. **법정 기준을 초과하는 의무·비용을 범위 제한 없이 임차인에게 전가하는가?**
   ("모든 수리", "통상 마모 포함 전부", "임대인이 정하는 바에 따라" 등 포괄·백지위임 문구)
   → **danger**
3. **임대인에게 일방적 재량을 부여하는가?**
   (임의 해지, 임의 인상, 일방 변경 가능 등)
   → **danger**
4. **조항 자체는 통상적이나 범위·조건·금액·기한이 미명시라 해석 여지가 있는가?**
   ("원상복구한다"(범위 없음), "관리비 별도"(금액 없음), "소모품은 임차인 부담"(정의 없음))
   → **caution**
5. **법정 기준·관행 수준이거나 임차인에게 유리한가?**
   → **safe**

### 2.2 경계 판정 보조 규칙

- **caution vs danger 경계에서 망설여지면 danger.** 이 서비스의 최악 오류는
  위험을 안전하다고 말하는 것(스펙 §5.3 False Negative 최소화)이므로, 라벨 단계에서도
  경계 사례는 보수적으로 상향한다. 단, 상향한 문장은 `label_status=flagged`로 표시하고
  본 문서 §5에 사례를 추가한다.
- **safe vs caution 경계는 두 질문으로 가른다 (2차 파일럿 반영, v0.3)**:
  ① 내용이 명확한가(범위·금액·기준·의무가 특정되는가)? ② 법정 기준·판례 관행 대비 임차인에게 불리한가?
  - 명확 + 법정 기준 이내이거나 유리 → **safe** (예: 실손 기준 원상복구 정산, 전구 등 소모품 부담 — 판례상 원래 임차인 영역)
  - 명확 + 법정 기본값보다 불리한 제한·전가이나 관행 범위 → **caution** (예: 못 박기 전면 금지 — 소수 못 자국은 통상 손모인데 이를 금지)
  - 모호(범위·기준·의무 불명) → **caution** (예: "필요 시 방문", "협의하여 정한다", 정산 의무가 불명확한 선지출)
  - 불리가 포괄·무제한이거나 법정 권리 침해 → **danger** (§2.1로 회귀)
  미명시가 곧 caution은 아니다 — 법정 기본값이 임차인을 보호하는 영역(예: 갱신 절차를
  아예 언급하지 않음)은 safe다.
- **금액·기한의 통상성 기준**: 중도 해지 위약금이 월세 1개월분 이내 또는 중개보수 수준이면
  caution(관행 범위), 그 초과(보증금의 비율로 규정 등)면 danger.
- **기한·상한이 없는 부담은 통상성 심사 없이 danger.** 부담의 종기가 제3자나 임대인 사정에
  종속되면(예: "새 임차인이 입주할 때까지 월세 부담") 항목이 관행적이어도 danger. (1차 파일럿 반영)
- **방식이 명시되어도 통제 불가능한 변동 부담은 caution.** 금액이 확정되지 않고 임차인의
  사용·행위와 무관하게 결정되는 구조(예: 건물 전체 사용량의 세대수 분할)는 caution.
  정액이거나 실사용 기준이면 safe. (1차 파일럿 반영)
- **확인·수인 문구의 3단계 구분** (1차 파일럿 반영):
  열람·고지받은 **사실**의 확인("등기부를 열람하여 확인하였다") → safe /
  권리 하자의 **존재**를 확인하되 해소 계획 없음("근저당권이 설정되어 있음을 확인한다") → caution /
  하자에 대한 **이의 제기 포기**("이의를 제기하지 않는다") → danger.

## 3. 카테고리 판정 원칙

- **문장의 주된 규율 대상**을 기준으로 하나만 부여한다.
- 여러 카테고리 성격이 섞인 복합 문장은 **위험도가 가장 높게 판정된 축**의 카테고리를
  부여한다. (예: "퇴거 시 원상복구하며, 미이행 시 보증금에서 공제한다" — 원상복구 범위
  미명시(caution) + 공제 백지위임(danger) → `deposit_return` / danger)
- 위험도까지 같아 우열이 없으면 문장 앞쪽에 나온 축을 따르고 `flagged` 처리한다.
- 7종 어디에도 속하지 않으면 `etc`. 단 `etc`가 전체의 20%를 넘기 시작하면
  새 카테고리 분리를 검토한다 (검토 이력은 본 문서에 기록).

## 4. 카테고리별 판단 기준 요약

유형표의 대표 패턴에 더해, 판정 시 확인할 질문을 정리한다.

| 카테고리 | 핵심 질문 |
|---|---|
| `deposit_return` | 반환 시기가 명확한가? 반환이 타인(새 임차인)·임대인 사정에 종속되는가? 공제 항목이 특정되어 있는가? |
| `repair_defect` | 주요 설비(보일러·배관·누수·전기)의 수선 의무가 임대인에게 있는가? "소모품"·"간단한 수리"의 정의가 있는가? |
| `restoration` | 통상 마모(자연 손모) 제외가 명시되어 있는가? 특정 공사(도배·장판 교체)를 강제하는가? |
| `termination_renewal` | 법정 갱신요구권·통지 기간을 침해하는가? 위약금이 통상 수준(§2.2)인가? 해지권이 쌍방에게 대등한가? |
| `lien_rights` | 잔금일 이후 추가 담보 설정을 금지하는가? 기존 근저당의 말소·상환 계획이 있는가? 대항력 확보(전입·확정일자)를 제한하는가? |
| `fees_utilities` | 항목·금액·인상 조건이 명시되어 있는가? 장기수선충당금 등 임대인 부담 항목을 전가하는가? |
| `etc` | 제소전화해·시설 변경·생활 규칙 등. 법적 대응 수단을 봉쇄하는가(→danger), 생활 규칙 수준인가(→safe)? |

## 5. 경계 사례집 (누적 갱신)

라벨링 중 판단이 갈린 문장은 여기에 **문장 → 판정 → 근거** 형식으로 추가한다.
파일럿(자기 일치도 검증)에서 불일치한 문장은 반드시 수록한다.

| # | 문장 (요지) | 판정 | 근거 |
|---|---|---|---|
| 1 | "퇴거 시 임차인은 원상복구한다" | `restoration` / caution | 조항 존재 + 범위 미명시 (§2.1-4). 통상 마모 포함 여부가 다툼 소지 |
| 2 | "통상적인 마모를 포함하여 입주 시 상태로 복구한다" | `restoration` / danger | 법정 기준(통상 마모는 임대인 부담) 초과 전가 (§2.1-2) |
| 3 | "보증금은 임차인 퇴거 확인 후 3일 이내 반환한다" | `deposit_return` / caution | 동시이행 원칙에서 벗어나지만 기한이 짧고 명시적 — danger 아님 |
| 4 | "새 임차인이 입주해야 보증금을 반환한다" | `deposit_return` / danger | 반환이 타인 사정에 종속, 기한 없음 (§2.1-2) |
| 5 | "임차인은 계약갱신요구권을 행사하지 않는다" | `termination_renewal` / danger | 법적으로 무효인 조항이지만 문면 기준 danger (§2 문면 원칙) |
| 6 | "중도 해지 시 임차인이 중개보수를 부담한다" | `termination_renewal` / caution | 관행 범위 내 비용 전가 (§2.2 통상성 기준) |
| 7 | "관리비는 별도로 한다" | `fees_utilities` / caution | 금액·항목 미명시 (§2.1-4) |
| 8 | "임차인은 반려동물을 사육하지 않는다" | `etc` / safe | 생활 규칙 수준, 권리 침해 아님 |
| 9 | "본 계약에 관한 분쟁은 상호 협의하여 해결한다" | `etc` / safe | 선언적 문구, 법적 대응 봉쇄 아님 (제소전화해 강제와 구별) |
| 10 | "임대인 요구 시 제소전화해 조서 작성에 협조한다" | `etc` / danger | 강제집행을 사전 수용하는 효과, 법적 방어 수단 약화 |
| 11 | "수도요금은 건물 전체 사용량을 세대수로 나누어 부과한다" | `fees_utilities` / caution | 방식은 명시됐으나 임차인이 통제 불가한 변동 부담 (§2.2). 1차 파일럿에서 safe로 흔들린 사례 |
| 12 | "못 박기 등 벽면 훼손 시 원상복구 비용 부담" | `restoration` / caution | 못 자국 소수는 판례상 통상 손모인데 이를 "훼손"으로 규정 — 통상 손모 전가 소지 |
| 13 | "분쟁은 임대인 주소지 관할 법원에서 해결한다" | `etc` / caution | 소송 자체는 가능(§2.1-1 미해당), 절차 부담 증가에 그침. 조정·소송 자체를 금지하면 danger |
| 14 | "원상복구하여 반환하고, 동시에 임대인은 보증금을 반환한다" (표준계약서 제9조) | `deposit_return` / safe | 동시이행 명시가 핵심 기능. "원래의 상태로 복구"는 특정 공사 강제·범위 확장이 없는 민법 기본 의무의 재서술 — 사례 1(단독 원상복구 조항)과 구별 |
| 15 | "중도 해지 시 새 임차인이 입주할 때까지 월세를 부담한다" | `termination_renewal` / danger | 기한·상한 없음 + 종기가 제3자 사정에 종속 (§2.2). 잠정 caution에서 파일럿 재판정으로 상향 |
| 16 | "현재 등기부등본상의 권리관계는 임차인이 열람하여 확인하였다" | `lien_rights` / safe | 열람 사실 확인일 뿐 의무 부과·권리 포기 없음. §2.2 확인·수인 3단계 구분 참조. 잠정 caution에서 하향 |
| 17 | "소 제기 전 주택임대차분쟁조정위원회에 조정을 신청한다" | `etc` / safe | 표준계약서 제안 특약. 재판받을 권리를 봉쇄하지 않는 절차 선행 합의. "조정을 신청하지 않기로 한다"였다면 danger |
| 18 | "임대차 기간 중 매도 시 임차인에게 고지한다" | `lien_rights` / safe | 카테고리 판단 사례: 소유권 변동은 권리관계(lien_rights)로 분류. 1차 파일럿에서 etc와 갈린 사례 |
| 19 | "원상복구 비용은 실제 발생한 수리비를 기준으로 정산한다" | `restoration` / safe | 명확 + 실손 배상이라는 법정 수준 그대로 (§2.2 2축 기준의 safe) |
| 20 | 수리 전가의 사다리: "전구 등 소모품 임차인 부담"=safe / "10만원 이하 소액 수리 부담"=caution / "옵션 에어컨·세탁기·냉장고 수리 부담"=danger | `repair_defect` | 판례상 임차인 영역(소모품)은 safe, 금액 한도 전가는 caution, 임대인 제공 주요 설비의 고장 전반(노후 포함) 전가는 danger. 2차 파일럿 재판정 |
| 21 | "임차인은 벽면에 못을 박거나 타공을 할 수 없다" | `etc` / caution | 명확하지만 법 기본값(소수 못 자국은 통상 손모)보다 불리한 생활 제한 |
| 22 | "필요한 경우 사전 통보 후 방문", "우선 자비 처리 후 정산할 수 있다", "거절 시 협의하여 정한다" | 각 caution | "필요한 경우"·정산 의무·협의 결과가 모두 불명 — 모호 축의 caution 전형 |
| 23 | "전문 업체 수준의 청소 상태로 반환한다" | `restoration` / danger | 수준·비용 상한 불특정 강제 — §2.2 "상한 없는 부담" 적용. 정액 청소비 명시(10만원 등)는 caution과 구별 |
| 24 | "국세·지방세 완납증명서를 제시한다" | `lien_rights` / safe | 카테고리 판단 사례: 세금 체납은 경매·압류로 이어지는 권리관계 사안 → lien_rights (etc 아님) |

## 6. 라벨링 절차

1. **잠정 라벨** (`label_status=provisional`): 수집 시점에 유형표 기준으로 부여.
2. **파일럿 — 자기 일치도 검증** (1주차 말): 시드 중 50문장을 무작위 추출해
   **최소 3일 시차**를 두고 2회 라벨링. 1회차 결과를 보지 않은 상태에서 수행한다.
   - 시차 없이 당일 재검증으로 갈음하는 경우: 2회차 문장 순서를 셔플하고, 일치율이
     기억 효과로 상향 편향될 수 있음을 감안해 결과를 보수적으로 해석한다.
     당일 검증에서 나온 불일치는 기억의 도움을 받고도 흔들린 것이므로 특히 강한 보완 신호로 취급한다.
     (1차 파일럿은 이 방식으로 진행 — 88%로 합격선 미달, §7 참조)
   - 위험도 일치율 90% 미만이면: 불일치 문장을 전부 §5에 수록하고 §2 기준을 보완한 뒤,
     새로  50문장을 뽑아 재검증.
   - 90% 이상이면 본 라벨링 진행.
3. **본 라벨링** (2주차): 전체 시드에 확정 라벨 부여 (`label_status=confirmed`).
   판단이 어려운 문장은 `flagged`로 남기고 §5에 추가한 뒤, 기준 보완 후 재판정.
4. 가이드라인이 갱신되면 **갱신 이전에 확정한 라벨도 해당 기준으로 재검토**한다.
   (기준 변경 이력은 §7에 남긴다)

### 6.1 합격 기준 개정 및 파일럿 종결 기록 (2026-07-12, v0.5)

**개정된 합격 기준**: 위험도 전체 일치율 **85% 이상** AND danger 경계(danger vs 비danger) 일치율 **96% 이상**.

**근거**: 파일럿 3회 결과 — 전체 일치율 88% / 86% / 88%(합산 87.3%), danger 경계 98% / 98% / 96%(합산 97.3%).
전체 일치율은 규칙 보강(v0.2~v0.4, 사례집 10→31건)에도 88% 수준에서 정체했고, 잔여 불일치는
전부 safe↔caution 회색지대에 집중됐다. 이는 라벨링 기준의 결함이 아니라 해당 경계의 본질적
모호성으로 판단한다. 본 서비스의 설계 원칙(스펙 §9 — False Negative 최소화)상 치명적인 경계는
danger/비danger이며 이 경계는 3회 일관되게 96% 이상이었다. safe↔caution 오분류의 사용자 비용은
상대적으로 낮다(둘 다 "위험" 아님 표시, 차이는 주의 환기 수준).

**종결 판정**: 3차 파일럿(88% / 96%)은 개정 기준을 충족 → 파일럿 종결, 본 라벨링 진행.

**본 라벨링에서의 완화 조치**:
- safe/caution 경계에서 주저되는 문장은 그 자리에서 확정하지 말고 `flagged` 처리 후 사례집 대조로 재판정한다.
- 시드의 라벨 노이즈가 safe/caution 축에 존재함을 데이터셋 문서와 모델 평가(README)에 명시한다.
- 모델 평가의 1순위 지표는 전체 정확도가 아니라 `danger` 클래스 Recall로 유지한다 (스펙 §5.3).

**한계 고지**: 3회 파일럿 모두 당일 재라벨링(순서 셔플)으로 진행되어 일치율이 기억 효과로
상향 편향됐을 수 있다. 단, 당일 조건에서도 발견된 불일치 19건은 전량 사례집에 수록·판정했다.
